# Crewly UI

## How to set up
1. Clone into your project folder `crewly/`.
2. Request for the docker-compose.yml file and place it at the root of `crewly/`.
3. Run `npm i` inside `crewly-api`.
4. To run with hot reloading, run `npm run dev`, or `docker compose up --build` to run with the API.

## Mantine UI Component Library
To make development simpler, we choose not to reinvent the wheel.
See [Mantine UI Documentation](https://mantine.dev/) for more information.
